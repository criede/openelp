Stór APT OpenELP DB9CR

⚠ D’aistrigh intleacht shaorga an leathanach seo go huathoibríoch agus d’fhéadfadh botúin a bheith ann. Is é an leagan Béarla an leagan údarásach. (English)

Pacáistí de OpenELP, an seachfhreastalaí (proxy) EchoLink foinse oscailte, do Raspberry Pi OS agus Debian, in dhá chomhpháirt — roghnaigh ceann amháin:

  • main: tógálacha forbartha laethúla ón gcód foinseach is déanaí den fhorc seo, ní eisiúintí cobhsaí.
  • release: na heisiúintí oifigiúla OpenELP ón mbuntionscadal (upstream) (0.9.3 agus níos nuaí), tógtha ó chód foinseach neamhathraithe na heisiúna leis na socruithe tógála céanna leis na pacáistí laethúla. Coinnítear gach eisiúint; bogann apt upgrade chuig gach eisiúint nua ón mbuntionscadal.

Féach an stór cód foinseach le haghaidh sonraí.

Buntionscadal & athruithe áitiúla

Is forc é seo a shioncronaítear go laethúil de cottsay/openelp, an tionscadal bunaidh OpenELP, le pacáistiú áitiúil (an stór APT seo) agus b'fhéidir athruithe breise curtha leis. Chun a fheiceáil go díreach cad atá difriúil ón mbuntionscadal ag am ar bith, déan comparáid beo ar GitHub: main an bhuntionscadail … main an fhorc seo.

Tús tapa

Rith ar an spriocchóras é (aimsítear an cód-ainm/an ailtireacht cheart go huathoibríoch):

# Iompórtáil an eochair shínithe phoiblí
curl -fsSL https://criede.github.io/openelp/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/openelp-db9cr.gpg

# Cuir foinse an stóir leis. Roghnaigh an chomhpháirt:
#   main     tógálacha forbartha laethúla
#   release  eisiúintí oifigiúla ón mbuntionscadal (0.9.3 agus níos nuaí)
component=release
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/openelp-db9cr.gpg arch=${arch}] https://criede.github.io/openelp ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/openelp-db9cr.list

sudo apt update
sudo apt install openelp

# Riachtanach roimh an gcéad tosú: socraigh pasfhocal (agus, más mian leat, an
# port, na seoltaí ceangail, an clárú agus na scagairí glaoshínte).
sudo editor /etc/openelp/ELProxy.conf

# Cumasaigh an seachfhreastalaí ag am tosaithe agus tosaigh anois é.
sudo systemctl enable --now openelp.service

# Seiceáil staid na seirbhíse agus lean a loga.
systemctl status openelp.service
journalctl -u openelp.service -f

Riachtanach: Diúltaíonn an seachfhreastalaí tosú fad is atá Password in /etc/openelp/ELProxy.conf fós socraithe go notset. Roghnaigh do phasfhocal féin; ná socraigh go PUBLIC é ach amháin más mian leat seachfhreastalaí poiblí a rith (in éineacht le RegistrationName uathúil).

Má thuairiscíonn apt update earráid 404 don fhoinse seo, níl cód-ainm do chórais á thógáil fós (féach an tábla thíos) — ina ionad sin, athraigh an cód-ainm in /etc/apt/sources.list.d/openelp-db9cr.list go ceann de na cinn a dtacaítear leo. Ina dhiaidh sin, tógfaidh sudo apt upgrade rialta tógálacha laethúla nua (main) nó eisiúintí nua ón mbuntionscadal (release) go huathoibríoch agus atosóidh sé seachfhreastalaí atá ag rith.

Ná cumasaigh an dá chomhpháirt ag an am céanna: suiteálann apt i gcónaí cibé leagan is airde, agus tógáil laethúil a bhíonn ann de ghnáth. Chun suiteáil atá ann cheana a athrú ó main go release, athraigh an chomhpháirt in /etc/apt/sources.list.d/openelp-db9cr.list, rith sudo apt update, ansin suiteáil leagan na heisiúna go sainráite (íosghrádú de ghnáth), m.sh. sudo apt install openelp=0.9.3-1~trixie.

Líonra agus balla dóiteáin

Ceanglaíonn cliaint EchoLink leis an seachfhreastalaí thar TCP ar an Port cumraithe (réamhshocrú 8100). Caithfidh an seachfhreastalaí féin a bheith inrochtana ón Idirlíon ar phoirt UDP 5198 agus 5199 (cuir ar aghaidh iad ar do ródaire má tá an seachfhreastalaí taobh thiar de NAT) agus teastaíonn rochtain amach uaidh ar phort TCP 5200 agus ar phoirt UDP 5198/5199. Ná lig ach do do chliaint féin port an tseachfhreastalaí a bhaint amach, mura bhfuil seachfhreastalaí poiblí á rith agat.

An seachfhreastalaí a úsáid le SvxLink

I gcumraíocht mhodúl EchoLink SvxLink (/etc/svxlink/svxlink.d/ModuleEchoLink.conf), dírigh é ar an seachfhreastalaí agus atosaigh SvxLink:

PROXY_SERVER=192.0.2.10    # seoladh an óstríomhaire OpenELP
PROXY_PORT=8100
PROXY_PASSWORD=your-password

Cumraítear an cliant oifigiúil EchoLink do ríomhairí pearsanta ar an mbealach céanna faoi Setup → Connections → Proxy.

Athruithe cumraíochta a chur i bhfeidhm

Ní léann OpenELP a chumraíocht ach ag am tosaithe. Tar éis duit /etc/openelp/ELProxy.conf a chur in eagar, atosaigh an tseirbhís (dícheanglaíonn sé seo naisc ghníomhacha na gcliant):

sudo systemctl restart openelp.service

Coinnítear athruithe áitiúla ar /etc/openelp/ELProxy.conf le linn uasghráduithe (is comhad cumraíochta dpkg é). Ní féidir ach le root an comhad a léamh, mar go bhfuil pasfhocal an tseachfhreastalaí ann.

Leagan níos sine a shuiteáil

Fanann leaganacha le déanaí ar fáil sa pool ar feadh tamaill tar éis iad a bheith ionadaithe (na cinn laethúla ar feadh seachtaine, na cinn seachtainiúla ar feadh míosa, na cinn mhíosúla ar feadh bliana — féach "Retention" (coinneáil) in UPSTREAM-SYNC.MD), mar sin is féidir droch-thógáil laethúil a rolladh siar de ghnáth. Ní bhaintear pacáistí eisiúna ón mbuntionscadal (comhpháirt release) choíche:

apt list -a openelp   # liostaíonn sé gach leagan atá fós sa stór
sudo apt install openelp=0.9.4~dev+daily20261108.12.1.g0123456789ab-1~trixie
sudo apt-mark hold openelp   # roghnach: cuireann sé cosc ar "apt upgrade" é a nuashonrú arís
# sudo apt-mark unhold openelp   # níos déanaí, chun nuashonruithe uathoibríocha a atosú

Pacáistí

PacáisteÁbhar
openelpAn deamhan seachfhreastalaí openelpd agus a leabharlann, an chumraíocht shamplach /etc/openelp/ELProxy.conf, seirbhís systemd (openelp.service, nach gcumasaítear go huathoibríoch) agus an leathanach lámhleabhair. Tógtha in aghaidh leabharlann PCRE2 an chórais, leis an gcur i bhfeidhm MD5 atá san áireamh (gan spleáchas ar OpenSSL) agus logáil trí syslog. Níl ceanntásca forbartha san áireamh.

Córais 32-giotán: Tógtar pacáistí armhf in aghaidh Raspbian (ARMv6+VFP), bunús Raspberry Pi OS 32-giotán, mar sin ritheann siad ar gach samhail Raspberry Pi lena n-áirítear an Pi 1, Zero agus Zero W, agus suiteálann siad ar Debian armhf freisin (tástáiltear an dá cheann). Ní thógtar i386 (ríomhairí pearsanta 32-giotán) ach do Debian 12: ní thacaíonn Debian 13 le córais i386 a shuiteáil a thuilleadh. Tá na gnéithe céanna sna pacáistí 32-giotán agus atá sna cinn 64-giotán.
