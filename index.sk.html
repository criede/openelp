APT repozitár OpenELP DB9CR

⚠ Táto stránka bola preložená automaticky pomocou umelej inteligencie a môže obsahovať chyby. Záväzná je anglická verzia. (English)

Balíky OpenELP, open-source proxy pre EchoLink, pre Raspberry Pi OS a Debian, v dvoch komponentoch — vyber si jeden:

  • main: denné vývojové zostavenia z najnovšieho zdrojového kódu tohto forku, nie stabilné vydania.
  • release: oficiálne vydania OpenELP z materského projektu (0.9.3 a novšie), zostavené z nezmeneného zdrojového kódu vydania s rovnakými nastaveniami zostavenia ako denné balíky. Každé vydanie sa zachováva; apt upgrade prejde na každé nové vydanie materského projektu.

Podrobnosti nájdeš v zdrojovom repozitári.

Materský projekt a lokálne zmeny

Toto je denne synchronizovaný fork projektu cottsay/openelp, pôvodného projektu OpenELP, s vlastným balíčkovaním (tento APT repozitár) a prípadne ďalšími zmenami navrch. Ak chceš kedykoľvek presne zistiť, čím sa fork líši od materského projektu, porovnaj ich naživo na GitHube: main materského projektu … main tohto forku.

Rýchly štart

Spusti na cieľovom systéme (správne kódové meno a architektúra sa zistia automaticky):

# Import verejného podpisového kľúča
curl -fsSL https://criede.github.io/openelp/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/openelp-db9cr.gpg

# Pridanie zdroja repozitára. Zvoľ komponent:
#   main     denné vývojové zostavenia
#   release  oficiálne vydania materského projektu (0.9.3 a novšie)
component=release
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/openelp-db9cr.gpg arch=${arch}] https://criede.github.io/openelp ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/openelp-db9cr.list

sudo apt update
sudo apt install openelp

# Povinné pred prvým spustením: nastav heslo (a voliteľne
# port, adresy na počúvanie, registráciu a filtre volacích značiek).
sudo editor /etc/openelp/ELProxy.conf

# Povolenie proxy pri štarte systému a jeho okamžité spustenie.
sudo systemctl enable --now openelp.service

# Kontrola stavu služby a sledovanie jej protokolu.
systemctl status openelp.service
journalctl -u openelp.service -f

Povinné: Proxy sa odmietne spustiť, kým má Password v /etc/openelp/ELProxy.conf stále hodnotu notset. Zvoľ si vlastné heslo; na PUBLIC ho nastav len vtedy, ak chceš prevádzkovať verejný proxy (spolu s jedinečným RegistrationName).

Ak apt update pre tento zdroj hlási chybu 404, pre kódové meno tvojho systému sa balíky zatiaľ nezostavujú (pozri tabuľku nižšie) — zmeň preto kódové meno v /etc/apt/sources.list.d/openelp-db9cr.list na niektoré z podporovaných. Potom bežný sudo apt upgrade automaticky stiahne nové denné zostavenia (main) alebo nové vydania materského projektu (release) a reštartuje bežiaci proxy.

Nepovoľuj oba komponenty súčasne: apt vždy nainštaluje vyššiu verziu, ktorou je zvyčajne denné zostavenie. Ak chceš prepnúť existujúcu inštaláciu z main na release, zmeň komponent v /etc/apt/sources.list.d/openelp-db9cr.list, spusti sudo apt update a potom explicitne nainštaluj verziu vydania (zvyčajne ide o prechod na nižšiu verziu), napr. sudo apt install openelp=0.9.3-1~trixie.

Sieť a firewall

Klienti EchoLink sa k proxy pripájajú cez TCP na nakonfigurovanom porte Port (predvolene 8100). Samotný proxy musí byť dosiahnuteľný z internetu na portoch UDP 5198 a 5199 (presmeruj ich na routeri, ak je proxy za NAT) a potrebuje odchádzajúci prístup k portu TCP 5200 a portom UDP 5198/5199. Povoľ prístup k portu proxy len svojim vlastným klientom, pokiaľ neprevádzkuješ verejný proxy.

Použitie proxy so SvxLink

V konfigurácii modulu EchoLink programu SvxLink (/etc/svxlink/svxlink.d/ModuleEchoLink.conf) nastav proxy a reštartuj SvxLink:

PROXY_SERVER=192.0.2.10    # adresa hostiteľa OpenELP
PROXY_PORT=8100
PROXY_PASSWORD=your-password

Oficiálny klient EchoLink pre PC sa konfiguruje rovnako v Setup → Connections → Proxy.

Uplatnenie zmien konfigurácie

OpenELP načítava svoju konfiguráciu len pri spustení. Po úprave /etc/openelp/ELProxy.conf reštartuj službu (tým sa prerušia aktívne spojenia klientov):

sudo systemctl restart openelp.service

Lokálne zmeny v /etc/openelp/ELProxy.conf sa pri aktualizáciách zachovajú (ide o konfiguračný súbor dpkg). Súbor môže čítať iba root, pretože obsahuje heslo proxy.

Inštalácia staršej verzie

Nedávne verzie zostávajú v poole po nahradení novšou ešte nejaký čas dostupné (denné počas týždňa, týždenné počas mesiaca, mesačné počas roka — pozri časť „Retention“ (uchovávanie) v UPSTREAM-SYNC.MD), takže chybné denné zostavenie sa dá zvyčajne vrátiť späť. Balíky vydaní materského projektu (komponent release) sa nikdy neodstraňujú:

apt list -a openelp   # vypíše všetky verzie, ktoré sú v repozitári ešte k dispozícii
sudo apt install openelp=0.9.4~dev+daily20261108.12.1.g0123456789ab-1~trixie
sudo apt-mark hold openelp   # voliteľné: zabráni tomu, aby ho "apt upgrade" opäť povýšil
# sudo apt-mark unhold openelp   # neskôr, na obnovenie automatických aktualizácií

Balíky

BalíkObsah
openelpDémon proxy openelpd a jeho knižnica, vzorová konfigurácia /etc/openelp/ELProxy.conf, služba systemd (openelp.service, nie je automaticky povolená) a manuálová stránka. Zostavený so systémovou knižnicou PCRE2, s pribalenou implementáciou MD5 (bez závislosti od OpenSSL) a protokolovaním cez syslog. Vývojové hlavičkové súbory nie sú súčasťou.

32-bitové systémy: balíky armhf sú zostavené pre Raspbian (ARMv6+VFP), základ 32-bitového Raspberry Pi OS, takže bežia na každom modeli Raspberry Pi vrátane Pi 1, Zero a Zero W a inštalujú sa aj na Debian armhf (oboje je testované). i386 (32-bitové PC) sa zostavuje len pre Debian 12: Debian 13 už nepodporuje inštaláciu systémov i386. 32-bitové balíky majú rovnaké funkcie ako 64-bitové.
