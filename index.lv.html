OpenELP DB9CR APT repozitorijs

⚠ Šī lapa ir automātiski tulkota ar mākslīgā intelekta palīdzību un var saturēt kļūdas. Noteicošā ir angļu valodas versija. (English)

OpenELP (atvērtā pirmkoda EchoLink starpniekserveris, Open Source EchoLink Proxy) pakotnes Raspberry Pi OS un Debian sistēmām divos komponentos — izvēlies vienu:

  • main: ikdienas izstrādes būvējumi no šī atzarojuma jaunākā pirmkoda, nevis stabili laidieni.
  • release: oficiālie sākotnējā OpenELP projekta laidieni (0.9.3 un jaunāki), būvēti no nemainīta sākotnējā projekta laidiena pirmkoda ar tiem pašiem būvēšanas iestatījumiem kā ikdienas pakotnes. Katrs laidiens tiek saglabāts; apt upgrade pāriet uz katru jaunu sākotnējā projekta laidienu.

Sīkāka informācija ir pirmkoda repozitorijā.

Sākotnējais projekts un vietējās izmaiņas

Šis ir katru dienu sinhronizēts atzarojums no cottsay/openelp — sākotnējā OpenELP projekta — ar vietēju pakošanu (šo APT repozitoriju) un, iespējams, citām papildu izmaiņām. Lai jebkurā brīdī precīzi redzētu, ar ko tas atšķiras no sākotnējā projekta, salīdzini tiešsaistē GitHub: upstream main … šī atzarojuma main.

Drošība: main pakotnes atmet no EchoLink tīkla saņemtās paketes, kas izraisītu zināmas SvxLink ievainojamības, pirms tās sasniedz SvxLink mezglu, kas izmanto šo starpniekserveri: nepareizi veidotas NDATA informācijas/tērzēšanas paketes (CVE-2026-73152 / GHSA-2m63-p9h9-p5rf: avārija, atmiņas satura atklāšana) un RTCP SDES paketes ar izsaukuma signālu, kas satur nederīgas rakstzīmes vai ir garāks par 32 rakstzīmēm (GHSA-6w9x-486p-ggrj: TCL komandu injekcija, bufera pārpildes). Tās arī ierobežo laiku, ko klients drīkst patērēt pieteikšanās procesam. Tas ir pagaidu risinājums, nevis aizstājējs SvxLink atjaunināšanai uz 26.05.2 vai jaunāku versiju. release pakotnes satur nemainītu sākotnējā projekta pirmkodu bez šīm izmaiņām; abas darbina starpniekserveri systemd smilškastē.

Ātrā sākšana

Izpildi mērķa sistēmā (pareizais koda nosaukums/arhitektūra tiek noteikti automātiski):

# Importē publisko parakstīšanas atslēgu
curl -fsSL https://criede.github.io/openelp/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/openelp-db9cr.gpg

# Pievieno repozitorija avotu. Izvēlies komponentu:
#   main     ikdienas izstrādes būvējumi
#   release  oficiālie sākotnējā projekta laidieni (0.9.3 un jaunāki)
component=release
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/openelp-db9cr.gpg arch=${arch}] https://criede.github.io/openelp ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/openelp-db9cr.list

sudo apt update
sudo apt install openelp

# Obligāti pirms pirmās palaišanas: iestati paroli (un pēc vēlēšanās
# portu, piesaistes adreses, reģistrāciju un izsaukuma signālu filtrus).
sudo editor /etc/openelp/ELProxy.conf

# Iespējo starpniekservera palaišanu sāknēšanas laikā un palaid to tūlīt.
sudo systemctl enable --now openelp.service

# Pārbaudi servisa stāvokli un seko tā žurnālam.
systemctl status openelp.service
journalctl -u openelp.service -f

Obligāti: Starpniekserveris atsakās startēt, kamēr Password failā /etc/openelp/ELProxy.conf joprojām ir notset. Izvēlies savu paroli; iestati to uz PUBLIC tikai tad, ja vēlies uzturēt publisku starpniekserveri (kopā ar unikālu RegistrationName).

Ja apt update šim avotam ziņo par kļūdu 404, tavas sistēmas koda nosaukumam pakotnes vēl netiek būvētas (skati tabulu zemāk) — tā vietā nomaini koda nosaukumu failā /etc/apt/sources.list.d/openelp-db9cr.list uz kādu no atbalstītajiem. Pēc tam parasta sudo apt upgrade komanda automātiski ielādē jaunus ikdienas būvējumus (main) vai jaunus sākotnējā projekta laidienus (release) un restartē strādājošu starpniekserveri.

Neiespējo abus komponentus vienlaikus: apt vienmēr instalē to versiju, kas ir augstāka, un parasti tas ir ikdienas būvējums. Lai pārslēgtu esošu instalāciju no main uz release, nomaini komponentu failā /etc/apt/sources.list.d/openelp-db9cr.list, izpildi sudo apt update un pēc tam skaidri instalē laidiena versiju (parasti tā ir versijas pazemināšana), piemēram, sudo apt install openelp=0.9.3-1~trixie.

Tīkls un ugunsmūris

EchoLink klienti savienojas ar starpniekserveri pa TCP konfigurētajā portā Port (noklusējums 8100). Pašam starpniekserverim jābūt sasniedzamam no interneta UDP portos 5198 un 5199 (pārsūti tos maršrutētājā, ja starpniekserveris atrodas aiz NAT), un tam nepieciešama izejoša piekļuve TCP portam 5200 un UDP portiem 5198/5199. Atļauj piekļuvi starpniekservera portam tikai saviem klientiem, ja vien neuzturi publisku starpniekserveri.

Starpniekservera izmantošana ar SvxLink

SvxLink EchoLink moduļa konfigurācijā (/etc/svxlink/svxlink.d/ModuleEchoLink.conf) norādi starpniekserveri un restartē SvxLink:

PROXY_SERVER=192.0.2.10    # OpenELP resursdatora adrese
PROXY_PORT=8100
PROXY_PASSWORD=your-password

Oficiālais EchoLink datora klients tiek konfigurēts tādā pašā veidā sadaļā Setup → Connections → Proxy.

Konfigurācijas izmaiņu piemērošana

OpenELP nolasa savu konfigurāciju tikai startēšanas laikā. Pēc faila /etc/openelp/ELProxy.conf rediģēšanas restartē servisu (tas pārtrauc aktīvos klientu savienojumus):

sudo systemctl restart openelp.service

Vietējās izmaiņas failā /etc/openelp/ELProxy.conf tiek saglabātas atjauninot (tas ir dpkg konfigurācijas fails). Tā kā fails satur starpniekservera paroli, to var lasīt tikai root un grupa openelp, ar kuras tiesībām darbojas serviss.

Vecākas versijas instalēšana

Nesenās versijas pēc aizstāšanas ar jaunākām vēl kādu laiku paliek pieejamas pool direktorijā (ikdienas — nedēļu, iknedēļas — mēnesi, ikmēneša — gadu; skati sadaļu “Retention” (saglabāšana) failā UPSTREAM-SYNC.MD), tāpēc sliktu ikdienas būvējumu parasti var atritināt atpakaļ. Sākotnējā projekta laidienu pakotnes (release komponents) nekad netiek dzēstas:

apt list -a openelp   # uzskaita visas versijas, kas vēl ir repozitorijā
sudo apt install openelp=0.9.4~dev+daily20261108.12.1.g0123456789ab-1~trixie
sudo apt-mark hold openelp   # neobligāti: neļauj "apt upgrade" to atkal atjaunināt
# sudo apt-mark unhold openelp   # vēlāk, lai atsāktu automātiskos atjauninājumus

Pakotnes

PakotneSaturs
openelpStarpniekservera dēmons openelpd un tā bibliotēka, konfigurācijas paraugs /etc/openelp/ELProxy.conf, systemd serviss (openelp.service, netiek iespējots automātiski; darbojas kā nepriviliģēts lietotājs openelp systemd smilškastē) un rokasgrāmatas lapa. Būvēts ar sistēmas PCRE2 bibliotēku, ar iekļauto MD5 implementāciju (bez OpenSSL atkarības) un žurnalēšanu caur syslog. Izstrādes galvenes faili nav iekļauti.
