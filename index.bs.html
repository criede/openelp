APT repozitorij OpenELP DB9CR

⚠ Ova stranica je automatski prevedena pomoću umjetne inteligencije i može sadržavati greške. Mjerodavna je engleska verzija. (English)

Paketi OpenELP, EchoLink proxyja otvorenog koda, za Raspberry Pi OS i Debian, u dvije komponente — odaberi jednu:

  • main: dnevni razvojni buildovi iz najnovijeg izvornog koda ovog forka, a ne stabilna izdanja.
  • release: zvanična izdanja OpenELP-a iz izvornog projekta (0.9.3 i novija), izgrađena iz neizmijenjenog izvornog koda izdanja s istim postavkama builda kao dnevni paketi. Svako izdanje se zadržava; apt upgrade prelazi na svako novo izdanje izvornog projekta.

Detalje potraži u izvornom repozitoriju.

Izvorni projekat i lokalne izmjene

Ovo je svakodnevno sinhronizovan fork projekta cottsay/openelp, originalnog projekta OpenELP, s vlastitim pakovanjem (ovaj APT repozitorij) i eventualnim daljim izmjenama povrh njega. Ako u bilo kojem trenutku želiš vidjeti po čemu se tačno fork razlikuje od izvornog projekta, uporedi ih uživo na GitHubu: main izvornog projekta … main ovog forka.

Brzi početak

Pokreni na ciljnom sistemu (ispravno kodno ime i arhitektura otkrivaju se automatski):

# Uvoz javnog ključa za potpisivanje
curl -fsSL https://criede.github.io/openelp/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/openelp-db9cr.gpg

# Dodavanje izvora repozitorija. Odaberi komponentu:
#   main     dnevni razvojni buildovi
#   release  zvanična izdanja izvornog projekta (0.9.3 i novija)
component=release
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/openelp-db9cr.gpg arch=${arch}] https://criede.github.io/openelp ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/openelp-db9cr.list

sudo apt update
sudo apt install openelp

# Obavezno prije prvog pokretanja: postavi lozinku (i po želji
# port, adrese za slušanje, registraciju i filtere pozivnih znakova).
sudo editor /etc/openelp/ELProxy.conf

# Omogući proxy pri pokretanju sistema i pokreni ga odmah.
sudo systemctl enable --now openelp.service

# Provjeri stanje servisa i prati njegov log.
systemctl status openelp.service
journalctl -u openelp.service -f

Obavezno: Proxy se odbija pokrenuti dok je Password u /etc/openelp/ELProxy.conf još uvijek notset. Odaberi vlastitu lozinku; postavi je na PUBLIC samo ako želiš pokretati javni proxy (zajedno s jedinstvenim RegistrationName).

Ako apt update za ovaj izvor prijavi grešku 404, za kodno ime tvog sistema paketi se još ne grade (pogledaj tabelu ispod) — umjesto toga promijeni kodno ime u /etc/apt/sources.list.d/openelp-db9cr.list u neko od podržanih. Nakon toga uobičajeni sudo apt upgrade automatski preuzima nove dnevne buildove (main) ili nova izdanja izvornog projekta (release) i ponovo pokreće aktivni proxy.

Nemoj istovremeno omogućiti obje komponente: apt uvijek instalira višu verziju, a to je obično dnevni build. Ako postojeću instalaciju želiš prebaciti s main na release, promijeni komponentu u /etc/apt/sources.list.d/openelp-db9cr.list, pokreni sudo apt update, a zatim eksplicitno instaliraj verziju izdanja (obično je to vraćanje na nižu verziju), npr. sudo apt install openelp=0.9.3-1~trixie.

Mreža i firewall

EchoLink klijenti se povezuju na proxy putem TCP-a na konfigurisanom portu Port (podrazumijevano 8100). Sam proxy mora biti dostupan s interneta na UDP portovima 5198 i 5199 (proslijedi ih na ruteru ako je proxy iza NAT-a) i treba odlazni pristup TCP portu 5200 i UDP portovima 5198/5199. Dozvoli pristup portu proxyja samo vlastitim klijentima, osim ako pokrećeš javni proxy.

Korištenje proxyja sa SvxLinkom

U konfiguraciji EchoLink modula za SvxLink (/etc/svxlink/svxlink.d/ModuleEchoLink.conf) usmjeri ga na proxy i ponovo pokreni SvxLink:

PROXY_SERVER=192.0.2.10    # adresa računara s OpenELP-om
PROXY_PORT=8100
PROXY_PASSWORD=your-password

Zvanični EchoLink klijent za PC konfiguriše se na isti način pod Setup → Connections → Proxy.

Primjena izmjena konfiguracije

OpenELP čita svoju konfiguraciju samo pri pokretanju. Nakon uređivanja /etc/openelp/ELProxy.conf ponovo pokreni servis (time se prekidaju aktivne veze klijenata):

sudo systemctl restart openelp.service

Lokalne izmjene u /etc/openelp/ELProxy.conf zadržavaju se pri nadogradnjama (to je konfiguracijska datoteka dpkg-a). Datoteku može čitati samo root jer sadrži lozinku proxyja.

Instalacija starije verzije

Nedavne verzije ostaju dostupne u poolu neko vrijeme nakon što ih zamijene novije (dnevne sedmicu dana, sedmične mjesec dana, mjesečne godinu dana — pogledaj odjeljak „Retention“ (zadržavanje) u UPSTREAM-SYNC.MD), pa se neispravan dnevni build obično može vratiti. Paketi izdanja izvornog projekta (komponenta release) nikad se ne uklanjaju:

apt list -a openelp   # prikazuje sve verzije koje su još u repozitoriju
sudo apt install openelp=0.9.4~dev+daily20261108.12.1.g0123456789ab-1~trixie
sudo apt-mark hold openelp   # opcionalno: sprečava da ga "apt upgrade" ponovo ažurira
# sudo apt-mark unhold openelp   # kasnije, za nastavak automatskih ažuriranja

Paketi

PaketSadržaj
openelpProxy daemon openelpd i njegova biblioteka, primjer konfiguracije /etc/openelp/ELProxy.conf, systemd servis (openelp.service, ne omogućava se automatski) i stranica priručnika. Izgrađen uz sistemsku biblioteku PCRE2, s ugrađenom implementacijom MD5 (bez zavisnosti od OpenSSL-a) i logovanjem putem sysloga. Razvojna zaglavlja nisu uključena.
